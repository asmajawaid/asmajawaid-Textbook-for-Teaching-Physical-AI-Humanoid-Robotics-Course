# Module 2: The Digital Twin

## Module Overview

Welcome to **Module 2: The Digital Twin**. In the previous module, you learned the abstract architecture of ROS 2—nodes, topics, and services. Now, we give those concepts a physical form.

A **Digital Twin** is a high-fidelity virtual replica of a physical robot and its environment. It is not merely a 3D model; it is a dynamic simulation that respects the laws of physics, mimics sensor noise, and interacts with the exact same software stack as the real machine. In this module, you will learn to construct these simulations using **Gazebo** (the standard for robotics physics) and explore **Unity** (for high-fidelity visualization).

Simulation is the primary workspace for a Physical AI engineer. It allows us to crash a million-dollar robot a thousand times without cost, train reinforcement learning agents in parallel, and validate safety systems before they ever touch the real world.

## Learning Objectives

By the end of this module, you will be able to:

*   **Define Digital Twins:** Understand the role of simulation in the "Sim-to-Real" development cycle.
*   **Master Gazebo:** specificially Gazebo Garden, to simulate rigid body dynamics and environments.
*   **Bridge Models:** Convert standard URDFs (from Module 1) into Simulation Description Format (SDF) for enhanced physical properties.
*   **Simulate Sensors:** Attach and configure virtual LIDARs, Depth Cameras (RealSense), and IMUs that publish standard ROS 2 messages.
*   **Evaluate Simulators:** Distinguish between physics-first engines (Gazebo) and rendering-first engines (Unity) for different use cases.
