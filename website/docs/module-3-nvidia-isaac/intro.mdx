# Module 3: NVIDIA Isaac Sim & AI Robotics

## Module Overview

Welcome to **Module 3: NVIDIA Isaac Sim & AI Robotics**. While Module 2 introduced the concept of the Digital Twin using Gazebo, Module 3 propels us into the era of **AI-driven robotics**.

NVIDIA Isaac Sim is a photorealistic, physically accurate virtual environment built on **NVIDIA Omniverse**. It leverages the Universal Scene Description (OpenUSD) format and GPU acceleration to simulate not just rigid bodies, but light, materials, and sensors with unprecedented fidelity. This module focuses on using Isaac Sim as a platform for training AI models, testing perception algorithms, and bridging the gap between simulation and reality.

We will explore the **Isaac ROS** ecosystem—hardware-accelerated ROS 2 packages that run on NVIDIA GPUs—and how they integrate with Isaac Sim to create high-performance navigation and manipulation systems.

## Learning Objectives

By the end of this module, you will be able to:

*   **Navigate Omniverse:** Use Isaac Sim to construct high-fidelity robotic environments.
*   **Bridge ROS 2 & Isaac:** Teleoperate robots and stream sensor data (RGB-D, LiDAR) between Isaac Sim and ROS 2 nodes.
*   **Generate Synthetic Data:** Use Isaac Replicator to generate annotated datasets for training computer vision models.
*   **Implement Visual Navigation:** Deploy Isaac ROS VSLAM and Nav2 for autonomous navigation in a simulated warehouse.
*   **Train with Reinforcement Learning:** Understand the pipeline for training robot policies using Isaac Lab (formerly Orbit/Isaac Gym).
*   **Master Sim-to-Real:** Apply domain randomization techniques to ensure simulated policies work on physical robots.

## Chapter Outline

### 1. [Isaac Sim & Synthetic Data](./isaac-sim-synthetic-data.mdx)
*   **Concept:** GPU-accelerated simulation and data generation.
*   **Topics:** Omniverse, OpenUSD, Isaac Replicator, and sensor modeling.
*   **Goal:** Generate a synthetic dataset for object detection.

### 2. [Isaac ROS: vSLAM & Nav2](./isaac-ros-vslam-nav2.mdx)
*   **Concept:** Hardware-accelerated perception and navigation.
*   **Topics:** Isaac ROS Bridge, VSLAM (Visual SLAM), Nav2 integration, and GEMs.
*   **Goal:** autonomously navigate a robot using visual odometry in Isaac Sim.

### 3. [Reinforcement Learning](./reinforcement-learning.mdx)
*   **Concept:** Teaching robots through trial and error at massive scale.
*   **Topics:** Isaac Lab, PPO (Proximal Policy Optimization), and massive parallel simulation.
*   **Goal:** Train a legged robot to walk or an arm to reach a target.

### 4. [Sim-to-Real Transfer](./sim-to-real.mdx)
*   **Concept:** Crossing the "Reality Gap."
*   **Topics:** Domain Randomization, System Identification, and closing the feedback loop.
*   **Goal:** Deploy a simulation-trained policy to a real (or realistically noisy) environment.
