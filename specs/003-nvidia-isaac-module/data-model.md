# Data Model for Module 3: NVIDIA Isaac Module

This document outlines the key data entities and their relationships relevant to the "NVIDIA Isaac Module" chapter. These entities represent the core components that users will interact with and understand within the Isaac Sim and ROS 2 ecosystem.

## 1. Simulated Robot Model

Represents a robotic system within the Isaac Sim environment.

-   **Name**: Unique identifier for the robot (e.g., "Franka Emika Panda", "Simple Wheeled Robot").
-   **Representation**:
    -   **URDF (Unified Robot Description Format)**: XML-based file describing the robot's kinematic and dynamic properties, visual appearance, and joints.
    -   **USD (Universal Scene Description)**: NVIDIA Omniverse native format, richer than URDF, supporting geometry, materials, lighting, physics, and behaviors.
-   **Joint States**: Current position, velocity, and effort of each joint.
-   **Sensor Configurations**: Details of attached sensors (type, pose, parameters).
-   **Actuators**: Mechanisms for controlling robot movement (e.g., motors, grippers).

## 2. Simulated Environment

Defines the virtual world in which the robot operates.

-   **USD Stage**: The root of the scene graph, containing all objects, lights, and physics properties.
-   **Static Objects**: Non-moving elements (e.g., walls, floors, furniture).
    -   Attributes: Geometry, material properties, collision meshes.
-   **Dynamic Objects**: Movable elements (e.g., other robots, interactable items, obstacles).
    -   Attributes: Geometry, material properties, collision meshes, mass, inertia, friction.
-   **Physics Properties**: Global parameters like gravity, friction coefficients, simulation time step.
-   **Lights**: Virtual light sources affecting rendering.
-   **Cameras**: Virtual viewpoints for rendering and synthetic data generation.

## 3. ROS 2 Nodes

Software processes that perform computation and communication within the ROS 2 ecosystem, interacting with Isaac Sim via the ROS 2 Bridge.

-   **Node Name**: Unique identifier for the ROS 2 node.
-   **Type**: Python or C++ executable.
-   **Topics**:
    -   **Published Topics**: Data streams produced by the node (e.g., `/cmd_vel`, `/joint_states`).
        -   Attributes: Message type, frequency, data content.
    -   **Subscribed Topics**: Data streams consumed by the node (e.g., `/scan`, `/camera/image_raw`).
        -   Attributes: Message type, frequency, data content.
-   **Services**: Request/response communication interfaces.
    -   Attributes: Service name, request message type, response message type.
-   **Actions**: Long-running, preemptible tasks (e.g., navigation goals, complex manipulation sequences).
    -   Attributes: Action name, goal message type, result message type, feedback message type.

## 4. Sensor Data

Raw or processed information acquired from simulated sensors.

-   **Point Clouds**: (from LiDAR/Depth cameras)
    -   Attributes: 3D coordinates (x, y, z), intensity values, timestamp, frame ID.
-   **Camera Images**: (from RGB, Depth, Semantic Segmentation cameras)
    -   Attributes: Image resolution (width, height), pixel format (RGB8, mono8), image data (pixel array), timestamp, frame ID.
-   **IMU Readings**: (Inertial Measurement Unit)
    -   Attributes: Linear acceleration (x, y, z), angular velocity (x, y, z), orientation (quaternion), timestamp, frame ID.
-   **Contact Sensors**: Boolean state indicating contact.
-   **Force/Torque Sensors**: Force and torque measurements.

## 5. Synthetic Dataset

Generated by Isaac Sim Replicator for AI model training.

-   **Image Data**: Rendered images of the simulated scene.
    -   Attributes: Image resolution, pixel format, image data.
-   **Ground Truth Annotations**: Corresponding labels for AI training.
    -   **Bounding Boxes**: (for object detection)
        -   Attributes: Object class, 2D coordinates (x_min, y_min, x_max, y_max), object ID.
    -   **Semantic Segmentation Masks**: (for pixel-level object classification)
        -   Attributes: Mask image (pixel values correspond to object classes), class mapping.
    -   **Instance Segmentation Masks**: (for individual object identification)
        -   Attributes: Mask image, instance ID mapping.
    -   **Depth Maps**: Distance from camera to surfaces.
    -   **Pose Annotations**: 6DoF pose (position and orientation) of objects.
-   **Metadata**: Information about the generation process (e.g., randomizations applied, camera intrinsic/extrinsic parameters).
